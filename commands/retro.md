A quick retrospective, kept honest and short. Run after a change ships.

1. Read the spec that was just shipped and the diff that delivered it.
2. Answer four questions concisely:
   - **What worked?** What made this cycle smooth.
   - **What dragged?** Where time was lost or the gate caught something.
   - **What surprised us?** Anything the spec missed or got wrong.
   - **One improvement** for next time (process or tooling), phrased as an action.
3. Append the result to `docs/RETRO.md` under a dated heading (create the file
   if absent). Keep it to a handful of lines — this is a ledger, not an essay.
4. If the improvement is a concrete change to the kit or the project, suggest
   turning it into the next `/vlkit:think`.
